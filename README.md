# 🎓 Fazal AI Maths Tutor

Fazal AI Maths Tutor is an interactive, AI-powered web application that helps learners understand mathematics through clear, step-by-step explanations.

## 🌐 Live Application

Try the application here:

https://fazal-ai-maths-tutor.streamlit.app

## ✨ Features

- Step-by-step mathematics solutions
- Simple explanations for difficult concepts
- Explain Like a Kid mode
- Automatic practice-question generation
- Answer checking with helpful feedback
- Interactive and animated user interface
- Conversation history during each session

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- HTML and CSS
- GitHub
- Streamlit Community Cloud
